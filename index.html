About TaskMate

A simple solution to everyday student productivity.

T

TaskMate

TaskMate is a student task management website designed to help students organize their academic and personal responsibilities in one place.

Our Features

  • Create, edit and delete tasks.
  • Organize tasks using categories.
  • Set priorities and deadlines.
  • Track completed and pending activities.
  • Save tasks using browser LocalStorage.
  • Access the website on different screen sizes.

Technology Used

HTML5, CSS3 and JavaScript.

Developed as a Web Development course mini-project.
